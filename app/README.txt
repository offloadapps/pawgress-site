Pawgress web version

Put this whole folder on any web host that serves https, then open the address in Safari on the iPhone,
tap Share > Add to Home Screen.

Quick free ways:
- Netlify Drop: go to app.netlify.com/drop and drag this folder onto the page. You get an https address straight away.
  (Create a free account afterwards to keep it; unclaimed sites are removed after a while.)
- GitHub Pages: upload these files to a GitHub repository and turn on Pages in the repository settings.

Everything is saved on the phone itself. No accounts, nothing is sent anywhere.
